**Free Degree Library** is a vibrant, student-powered educational platform engineered specifically for Undergraduate (UG) and Postgraduate (PG) students. Our goal is simple: eliminate academic friction by enabling peers to upload, categorize, search, and share study materials, lecture notes, lab manuals, and solved Previous Year Question Papers (PYQs) in an accessible, zero-cost ecosystem.

---

## ✨ Platform Highlights & Features

- 🏠 **Smart Repository (Home):** Rapid search with keyword matching and custom category filters (Computers, Business, Commerce, Sciences, Law).
- 📤 **Peer-to-Peer Sharing (Uploads):** Smooth file uploads allowing students to assist classmates by publishing notes directly from mobile or desktop devices.
- 💬 **Interactive Student Community Forum:** An integrated discussion arena featuring academic threads, peer polling, upvote/downvote engagement, and verified instructor comments.
- ⚡ **Important Questions & Exam Prep:** Curated semester exam preparation sheets, study guides, and vital lecture checkpoints (`important.html`).
- 🎓 **Dedicated MCA & PG Hub:** Specialized computer applications section featuring extensive SV University and Andhra University course materials.
- 📑 **ICET Solved PYQ Vault:** Comprehensive historical question paper database structured by examination shift and academic year.
- ℹ️ **Responsive About Hub & Feature Showcase:** Dedicated site documentation page (`about.html`) equipped with touch-friendly mobile auto-sliding carousels and detailed developer attribution.
- 🔔 **Automated Email Newsletters & Alerts:** Real-time email dispatching triggered when new study notes, polling events, or urgent administrative announcements are published.

---

## 🛠️ Technical Stack & Architecture

- **Frontend Design System:** Built with semantic HTML5 and vanilla CSS (`style.css`), emphasizing modern typography (Google Fonts), retro glassmorphic cards, responsive drop-shadow grids, and micro-hover interactions without bloated external CSS libraries.
- **Client-Side Logic:** Modular vanilla JavaScript (`app.js` / `app.min.js`) featuring real-time DOM filtering, resilient JSON parser validation (`safeJsonParse`), and swipe-enabled mobile carousel controllers.
- **Backend Services:** High-performance PHP API routing (`api/proxy.php`) tailored for broad compatibility across free and enterprise Linux hosting providers.
- **Database & Persistence:** MySQL/MariaDB schema designed for atomic handling of study file paths, community forums, comment thread nesting, tag parsing, and subscriber tracking.
- **Security & Moderation (Admin):** Equipped with a protected Administrative Control Dashboard (`admin.html`) featuring strict credential verification, brute-force visual error indicators, password toggle toggling, and an automated mathematical calculation bot-shield challenge upon failed login attempts.
